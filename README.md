API 명세서

1. 회원가입 API (POST /api/users/signup)
설명: 새로운 사용자를 시스템에 등록합니다.

Request Body (JSON):

JSON

{

  "email": "user@example.com",
  
  "password": "password1234"
  
}


성공 응답 (Success): 
201 Created

실패 응답 (Fail):

400 Bad Request: 이메일 형식이 잘못되었을 때.

409 Conflict: 이미 존재하는 이메일일 때.


----------------------------------------------------------------------------------------------------------------------------------------------


2. 로그인 API (POST /api/users/login)
설명: 이메일과 비밀번호를 확인하고 인증 토큰(JWT)을 발급합니다.

Request Body: 회원가입과 동일

성공 응답: 
200 OK

실패 응답:

401 Unauthorized: 비밀번호가 틀렸거나 가입되지 않은 이메일일 때.


----------------------------------------------------------------------------------------------------------------------------------------------


3. 로그아웃 API (POST /api/users/logout)
   
설명: 현재 접속된 유저의 인증 세션을 종료합니다.


----------------------------------------------------------------------------------------------------------------------------------------------

4. 이메일 중복 체크 API (GET /api/users/check-email)

설명: 회원가입 전, 입력한 이메일이 이미 DB에 존재하는지 확인합니다.

URL Parameter (Query String):

email: 중복 확인을 하려는 이메일 주소

예시: /api/users/check-email?email=test@example.com

1. 성공 응답 (사용 가능한 이메일일 때)

Status Code: 200 OK

Response Body:

JSON

{

  "isAvailable": true,
  
  "message": "사용 가능한 이메일입니다."
  
}

2. 실패 응답 (이미 가입된 이메일일 때)
   
Status Code: 409 Conflict (이미 서버에 리소스가 존재하여 충돌이 발생했다는 의미)

Response Body:

JSON

{

  "isAvailable": false,
  
  "message": "이미 사용 중인 이메일입니다."
  
}

3. 실패 응답 (입력 형식이 잘못되었을 때)
   
Status Code: 400 Bad Request

Response Body:

JSON
{

  "message": "유효하지 않은 이메일 형식입니다."
  
}
