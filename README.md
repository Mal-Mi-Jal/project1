API 명세서


----------------------------------------------------------------------------------------------------------------------------------------------

1. 회원가입 API (POST /api/users/signup)
설명: 새로운 사용자를 시스템에 등록합니다.

Request Body (JSON):

JSON

{

  "email": "user@example.com",
  
  "password": "password1234"
  
}


성공 응답 (Success)

201 Created

실패 응답 (Fail)

400 Bad Request: 이메일 형식이 잘못되었을 때.

409 Conflict: 이미 존재하는 이메일일 때.


----------------------------------------------------------------------------------------------------------------------------------------------


2. 로그인 API (POST /api/users/login)
설명: 이메일과 비밀번호를 확인하고 인증 토큰(JWT)을 발급합니다.

Request Body: 회원가입과 동일

성공 응답

200 OK

실패 응답

401 Unauthorized: 비밀번호가 틀렸거나 가입되지 않은 이메일일 때.


----------------------------------------------------------------------------------------------------------------------------------------------


3. 로그아웃 API (POST /api/users/logout)
   
설명: 현재 접속된 유저의 인증 세션을 종료합니다.


----------------------------------------------------------------------------------------------------------------------------------------------

4. 이메일 중복 체크 API (GET /api/users/check-email)

설명: 회원가입 전, 입력한 이메일이 이미 DB에 존재하는지 확인합니다.

URL Parameter (Query String):

email: 중복 확인을 하려는 이메일 주소

예시: /api/users/check-email?email=test@example.com

1) 성공 응답 (사용 가능한 이메일일 때)

Status Code: 200 OK

Response Body:

JSON

{

  "isAvailable": true,
  
  "message": "사용 가능한 이메일입니다."
  
}

2) 실패 응답 (이미 가입된 이메일일 때)
   
Status Code: 409 Conflict (이미 서버에 리소스가 존재하여 충돌이 발생했다는 의미)

Response Body:

JSON

{

  "isAvailable": false,
  
  "message": "이미 사용 중인 이메일입니다."
  
}

3. 실패 응답 (입력 형식이 잘못되었을 때)
   
Status Code: 400 Bad Request

Response Body:

JSON

{

  "message": "유효하지 않은 이메일 형식입니다."
  
}

게시물 API 명세서 (Post API)



----------------------------------------------------------------------------------------------------------------------------------------------


1. 게시물 생성 (POST /api/posts)

설명: 새로운 글을 작성합니다. (로그인한 사용자만 가능)

Request Body (JSON):

JSON

{

  "title": "안녕",
  
  "content": "안녕안녕!",
  
  "writerEmail": "user@example.com"
  
}

성공 응답: 201 Created (생성된 게시물 상세 데이터 반환)


----------------------------------------------------------------------------------------------------------------------------------------------


2. 게시물 전체 조회 (GET /api/posts)

설명: 모든 게시물을 목록 형태로 가져옵니다.

성공 응답: 200 OK

Response Body: (게시물 리스트)

JSON

[

  { "id": 1, "title": "첫 글", "writerEmail": "a@a.com", "createdAt": "2026-04-07" },
  
  { "id": 2, "title": "두 번째 글", "writerEmail": "b@b.com", "createdAt": "2026-04-07" }
  
]


----------------------------------------------------------------------------------------------------------------------------------------------


3. 특정 작성자의 게시물 조회 (GET /api/posts/user/{email})
   
설명: 특정 사용자가 쓴 글만 필터링해서 보여줍니다.

URL Parameter: {email} (예: /api/posts/user/test@test.com)

성공 응답: 200 OK (해당 유저의 게시물 리스트)


----------------------------------------------------------------------------------------------------------------------------------------------


4. 게시물 수정 (PUT /api/posts/{id})
   
설명: 내가 쓴 글의 제목이나 내용을 고칩니다.

Request Body: 수정할 title 혹은 content

실패 응답: 403 Forbidden (작성자가 아닌 사람이 수정을 시도할 때)


----------------------------------------------------------------------------------------------------------------------------------------------


5. 게시물 삭제 (DELETE /api/posts/{id})

설명: 게시물을 삭제합니다.

성공 응답: 204 No Content (성공적으로 삭제되어 돌려줄 내용이 없음)


----------------------------------------------------------------------------------------------------------------------------------------------



댓글 API 명세서 (Comment API)



----------------------------------------------------------------------------------------------------------------------------------------------


1. 댓글 작성 (POST /api/comments)
   
설명: 특정 게시물에 댓글을 남깁니다.

Request Body (JSON):

JSON

{

  "postId": 1, 
  
  "content": "안녕안녕!",
  
  "writerEmail": "reviewer@test.com"

}

성공 응답: 201 Created


----------------------------------------------------------------------------------------------------------------------------------------------


2. 게시물별 댓글 조회 (GET /api/posts/{postId}/comments)
   
설명: 특정 게시물에 달린 모든 댓글을 불러옵니다. (보통 게시물 상세 보기 때 같이 사용해요)

성공 응답: 200 OK

Response Body:

JSON

[

  { "id": 101, "content": "안녕안녕!", "writerEmail": "a@a.com", "createdAt": "2026-04-07" },
  
  { "id": 102, "content": "안녕!", "writerEmail": "b@b.com", "createdAt": "2026-04-07" }
  
]


----------------------------------------------------------------------------------------------------------------------------------------------


3. 댓글 수정 (PUT /api/comments/{id})
   
설명: 내가 쓴 댓글 내용을 수정합니다.

Request Body: { "content": "수정된 댓글 내용입니다." }

실패 응답: 403 Forbidden (남이 쓴 댓글을 수정하려 할 때)


----------------------------------------------------------------------------------------------------------------------------------------------


4. 댓글 삭제 (DELETE /api/comments/{id})
   
설명: 댓글을 삭제합니다.

성공 응답: 204 No Content

좋아요 API 명세서


----------------------------------------------------------------------------------------------------------------------------------------------


1. 좋아요 등록 (POST /api/likes)

설명: 특정 게시물에 좋아요를 표시합니다.

Request Body: { "postId": 1, "userEmail": "test@test.com" }

성공 응답: 201 Created


----------------------------------------------------------------------------------------------------------------------------------------------


2. 좋아요 취소 (DELETE /api/likes)
   
설명: 눌렀던 좋아요를 취소합니다.

Request Body (또는 Query String): { "postId": 1, "userEmail": "test@test.com" }

성공 응답: 204 No Content
